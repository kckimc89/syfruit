세계 과일도감 V3

이번 버전 주요 기능
- 과일 카드/사진을 누르면 바로 상세정보
- 새로운 과일 발견: 지역/나라 선택 → 과일 목록 → 이미 등록된 과일은 비활성화
- 한국 생산 여부/주요 생산지역/자연 수확시기 분리 표시
- 상세한 기본 과일 설명 제공
- 사진 등록/교체/삭제 및 백업/복원
- 대표 생산국 클릭 → 나라 정보와 연결된 과일 보기
- 세계지도 탐험: 주요 과일 생산국을 지도에서 눌러 나라 정보와 도감 과일로 연결
- 기존 V2 저장키를 유지하여 기존 데이터 이어받기

주의: 세계지도는 어린이 학습용 간단 지도입니다. 국가 위치를 익히는 용도로 사용하고, 정확한 국경선/면적 비교가 필요한 경우 별도의 지도 자료를 참고하세요.

아이패드 사용
1. ZIP을 풀어 기존 GitHub Pages 저장소의 파일을 교체합니다.
2. 기존 사이트 주소를 그대로 사용합니다.
3. 아이패드 Safari에서 새로고침합니다.
4. 홈 화면에 추가한 웹앱은 저장영역이 Safari와 다를 수 있으므로, 기존 데이터를 옮길 때는 도감의 백업/복원 기능을 사용하세요.
